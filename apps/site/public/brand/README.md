# Steamfield Arcade brand pack

Generated by `apps/site/src/brand.ts` (`pnpm --filter @arcade/site brand`, needs `rsvg-convert`). Edit that file and regenerate rather than editing these by hand. Everything is pixel art on a whole-number grid: scale PNGs by whole multiples with nearest-neighbour, or use the SVGs.

| File | Use |
| --- | --- |
| `mark.svg`, `mark-{64,256,512,1024}.png` | The invader mark on a transparent ground. Its ink outline keeps it readable on light backgrounds. |
| `mark-tile.svg`, `mark-tile-{180,512,1024}.png` | The mark centred on an ink square: app icons, avatars, the favicon. |
| `wordmark.svg`, `wordmark.png` | STEAMFIELD over ARCADE, transparent ground. |
| `lockup.svg`, `lockup.png` | Mark beside the wordmark. |
| `og-image.svg`, `og-image.png` | 1200x630 link preview used by the landing page's `og:image`. |
