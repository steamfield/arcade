# Asset credits

`nature.glb`: trees, bushes, ferns, flowers, grass, rocks and pebbles from the Stylized Nature MegaKit
(Standard) by Quaternius, CC0 1.0. https://quaternius.com/packs/stylizednaturemegakit.html, downloaded
from https://opengameart.org/content/stylized-nature-megakit. Rebuild with
`games/rush-racers-3d/scripts/build-nature-kit.sh <kit>/glTF`; the script lists which models are
included.

`forest-cards.webp` and `forest-cards.json` are the low-tier views and bounds baked from that
same kit. To rebuild just those files from the shipped GLB, run
`node games/rush-racers-3d/scripts/bake-forest.mjs` from the repo root.
